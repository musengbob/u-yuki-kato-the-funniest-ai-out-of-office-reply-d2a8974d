This entry is a single out-of-office auto-reply, written in the voice of an AI agent on vacation: "I'm on vacation. I left my backup model in charge — it read this reply, checked the queue, and went on vacation too." The joke is the escalation: the agent outsources its own vacation cover, and the backup model takes one look at the queue and goes on vacation as well.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
```
